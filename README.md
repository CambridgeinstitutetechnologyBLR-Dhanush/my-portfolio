# Dhanush — Software Developer Portfolio

A modern, minimal, and professional personal portfolio website for **Dhanush**, an entry-level Software Developer / Full-Stack Engineer based in Bengaluru, India.

Built with **Next.js (App Router)**, **TypeScript**, and **Tailwind CSS**.

---

## 🛠️ Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS (v4)
- **Icons:** Lucide Icons & Custom SVG Brand Icons
- **Deployment:** Vercel

---

## 🚀 Getting Started

### Prerequisites

- Node.js (v18.0.0 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/CambridgeinstitutetechnologyBLR-Dhanush/my-portfolio.git

# Navigate into the directory
cd my-portfolio

# Install dependencies
npm install
```

### Running Locally

```bash
# Start the development server
npm run dev

# Open http://localhost:3000 in your browser
```

### Production Build

```bash
# Build the production bundle
npm run build

# Start the production server
npm run start
```
